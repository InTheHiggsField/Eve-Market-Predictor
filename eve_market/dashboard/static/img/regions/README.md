# Region backgrounds

Drop one image per market here, named after the market (case doesn't matter):

    Jita.jpg  Amarr.jpg  Dodixie.jpg  Hek.jpg  Rens.jpg  Zarzakh.jpg

`.jpg`, `.jpeg`, `.png` and `.webp` all work. About 1920x1080 and under ~500 KB each keeps pages fast
(the GitHub Pages build copies this folder as is). The dashboard picks files up on the next page load.

A market without an image gets a faction-tinted nebula drawn in CSS, so nothing breaks if one is missing.

Optional `credits.json` puts a small credit in the corner, e.g. `{"Jita": "Screenshot: Fly Templeton"}`.

Licensing: your own in-game screenshots are fine to use on a free, non-commercial fan site under CCP's
content creation terms, as long as the site carries CCP's copyright notice (the footer does).
Don't use other people's screenshots or art without their permission.
